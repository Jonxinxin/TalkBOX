# 金牌销售话术库

一个基于 PySide6 和 PySide6-Fluent-Widgets 开发的 Windows 桌面话术管理小工具。它适合客服、销售、电销等需要频繁复制和发送固定话术的场景，可以把常用话术集中管理，并通过复制或拖拽快速发送到微信等聊天窗口。

## 功能特性

- 话术列表管理：新增、编辑、删除常用话术。
- 快速复制：点击复制按钮或双击话术卡片，即可复制完整话术。
- 搜索过滤：通过顶部搜索框快速筛选话术。
- 右键菜单：右键话术可置顶、取消置顶或删除。
- 置顶标记：置顶话术会显示醒目的“置顶”标签。
- 置顶数量限制：最多支持 5 条置顶话术。
- 拖拽发送：可将话术从软件中拖拽到支持文本拖放的输入框，例如微信输入框。
- 拖拽遮罩：拖拽话术时显示遮罩，明确提示当前拖拽状态。
- 窗口固定：支持将软件窗口固定在最前方，方便边聊边取话术。
- 本地存储：话术数据保存在用户应用数据目录，无需数据库。
- 自定义图标：默认读取项目根目录下的 `app.ico` 作为窗口图标。

## 运行环境

- Windows
- Python 3.9+
- PySide6
- PySide6-Fluent-Widgets

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动项目

```bash
python main.py
```

启动后，软件会自动显示在屏幕右侧。

## 使用说明

- 点击 `+` 按钮新增话术。
- 点击话术右侧的编辑按钮修改话术。
- 点击话术右侧的复制按钮复制话术。
- 双击话术卡片也可以复制话术。
- 右键话术卡片可以置顶、取消置顶或删除。
- 按住话术卡片并拖拽到微信输入框，可尝试直接填入话术文本。
- 点击顶部右侧的图钉按钮，可以切换窗口是否固定在最前方。

## 数据说明

话术数据默认保存在当前 Windows 用户的应用数据目录：

```text
%APPDATA%\Talkbox\talk_data.json
```

程序会自动创建该目录。旧版本如果在程序目录下存在 `talk_data.json`，新版第一次运行时会自动读取并迁移到上面的用户数据目录。

数据格式示例：

```json
[
    {
        "content": "您好，这边可以帮您办理宽带套餐"
    },
    {
        "content": "现在办理可享受限时优惠活动",
        "pinned": true,
        "original_index": 1
    }
]
```

字段说明：

- `content`：话术内容。
- `pinned`：是否置顶。
- `original_index`：取消置顶时用于尽量恢复原始排序。

## 打包建议

如果需要发布为 Windows 可执行文件，可以使用 PyInstaller：

```bash
pip install pyinstaller
pyinstaller -F -w --icon=app.ico main.py
```

打包后不需要把 `talk_data.json` 放在程序同目录。程序会自动在 `%APPDATA%\Talkbox\` 下创建和保存话术数据。

## 说明

拖拽发送依赖目标软件是否支持接收 `text/plain` 文本拖放。如果某些输入框不支持拖放，可以继续使用复制按钮或双击复制。
