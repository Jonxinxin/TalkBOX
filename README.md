# 金牌销售话术库

一个基于 PySide6 和 PySide6-Fluent-Widgets 开发的 Windows 桌面话术管理小工具。它适合客服、销售、电销等需要频繁复制和发送固定话术的场景，可以把常用话术集中管理，并通过复制或拖拽快速发送到微信等聊天窗口。

## 直接下载

前往 [GitHub Releases](https://github.com/Jonxinxin/TalkBOX/releases/latest) 下载最新的 Windows 64 位版本：

- `TalkBOX.exe`：下载后双击运行，无需安装 Python。
- `TalkBOX-版本号-windows-x64.zip`：包含可执行程序和使用说明，解压后运行 `TalkBOX.exe`。

升级时关闭旧版，再运行新版程序即可；话术、图片和 PDF 仍保存在 `%APPDATA%\Talkbox\`。

## 功能特性

- 话术列表管理：新增、编辑、删除常用文字话术。
- 图片话术管理：支持添加图片到话术库，并在列表中显示缩略图。
- PDF 文件管理：支持导入 PDF，保留原文件名，并可分类、搜索、替换和删除。
- 快速复制：点击复制按钮或双击话术卡片，即可复制完整话术。
- 图片复制：图片话术可直接复制到剪贴板。
- PDF 复制：PDF 可作为文件复制到剪贴板，方便粘贴到支持文件粘贴的聊天窗口。
- 搜索过滤：通过顶部搜索框快速筛选话术。
- 话术分类：支持“开场”“电表”“报价”“售后”四个固定分类，可在新增、编辑或右键菜单中设置。
- 分类筛选：点击顶部分类按钮筛选话术，并可配合关键词搜索。
- 两行预览：较长的话术显示为两行，超出部分以省略号显示。
- 右键菜单：右键话术可置顶、取消置顶或删除。
- 置顶标记：置顶话术会显示醒目的“置顶”标签。
- 自由排序：点击底部“调整顺序”，可拖动排列置顶话术和普通话术，保存后重启仍保留顺序。
- 置顶不限数量：置顶话术始终排在普通话术前面，也可在排序窗口内调整彼此顺序。
- 新增靠前：新文字、图片和 PDF 默认放在普通话术最前面，方便立即使用。
- 拖拽发送：可将文字、图片或 PDF 从软件中拖拽到支持对应内容拖放的聊天窗口，例如微信输入框。
- 拖拽遮罩：拖拽话术时显示遮罩，明确提示当前拖拽状态。
- 窗口固定：支持将软件窗口固定在最前方，方便边聊边取话术。
- 本地存储：话术数据保存在用户应用数据目录，无需数据库。
- 自定义图标：默认读取项目根目录下的 `app.ico` 作为窗口图标。

## 运行环境

- Windows
- Python 3.9+
- PySide6
- PySide6-Fluent-Widgets

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动项目

```bash
python main.py
```

启动后，软件会自动显示在屏幕右侧。

## 使用说明

- 点击 `+` 按钮新增话术。
- 点击顶部图片按钮添加图片，点击其右侧的文档按钮（“添加 PDF”）导入 PDF 文件。
- PDF 以文件形式保存，扫描件也可以导入；点击复制按钮或双击 PDF 卡片后，可粘贴到支持文件粘贴的聊天窗口，也可直接拖拽发送。
- PDF 卡片显示原文件名，可按文件名搜索；点击编辑按钮可替换文件，右键可设置分类、置顶或删除。
- 点击话术右侧的编辑按钮修改话术。
- 点击话术右侧的复制按钮复制话术。
- 双击话术卡片也可以复制话术。
- 右键话术卡片可以置顶、取消置顶或删除。
- 点击底部“调整顺序”或右键选择“调整顺序…”，在各组内拖动条目后点击“保存”。排序窗口显示全部话术，可分别调整置顶组和普通组。
- 新增话术排在普通列表最前；置顶数量不限，取消置顶后也会移到普通列表最前。
- 在新增或编辑窗口中选择分类，也可以右键话术卡片选择“设置分类”。
- 点击顶部“全部”“开场”“电表”“报价”“售后”按钮切换筛选范围。
- 按住话术卡片并拖拽到微信输入框，可尝试直接填入话术文本。
- 点击顶部右侧的图钉按钮，可以切换窗口是否固定在最前方。

## 数据说明

话术数据默认保存在当前 Windows 用户的应用数据目录：

```text
%APPDATA%\Talkbox\talk_data.json
```

程序会自动创建该目录。旧版本如果在程序目录下存在 `talk_data.json`，新版第一次运行时会自动读取并迁移到上面的用户数据目录。

图片文件会保存到：

```text
%APPDATA%\Talkbox\images
```

PDF 文件会保存到：

```text
%APPDATA%\Talkbox\pdfs\<独立目录>\原文件名.pdf
```

导入时会复制一份 PDF，即使移动或删除原文件，库中的 PDF 仍可使用。同名文件可以分别导入；替换或删除 PDF 卡片时只清理软件保存的副本。

数据格式示例：

```json
[
    {
        "content": "您好，这边可以帮您办理宽带套餐",
        "category": "开场"
    },
    {
        "content": "现在办理可享受限时优惠活动",
        "pinned": true
    },
    {
        "type": "image",
        "image": "images/example.png"
    },
    {
        "type": "pdf",
        "pdf": "pdfs/example/产品报价.pdf",
        "category": "报价"
    }
]
```

字段说明：

- `content`：话术内容。
- `category`：话术分类，支持 `开场`、`电表`、`报价`、`售后`；缺省或其他值按未分类处理。
- `type`：话术类型，图片为 `image`，PDF 为 `pdf`；旧版文字话术可不带该字段。
- `image`：图片相对路径。
- `pdf`：PDF 相对路径，末尾保留原文件名。
- `pinned`：是否置顶。
- 数组顺序保存手动排序；置顶组始终在普通组之前。旧版的 `original_index` 字段不再用于排序。

## 项目结构

```text
.
├── app.ico             # 窗口图标
├── main.py             # 主程序
├── requirements.txt    # Python 依赖
├── requirements-build.txt # 打包依赖
├── TalkBOX.spec         # PyInstaller 打包配置，包含窗口图标
├── tests/              # PDF 导入、排序及现有功能的回归测试
└── README.md           # 项目说明
```

## 运行测试

```bash
python -m unittest discover -s tests -v
```

测试使用临时数据目录和离屏界面，不会改动现有话术库或系统剪贴板。

## 打包 Windows 可执行文件

在 Windows 上安装依赖，使用项目自带的 PyInstaller 配置打包：

```bash
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm TalkBOX.spec
```

可执行文件生成在 `dist/TalkBOX.exe`，已包含运行依赖和 `app.ico`，可以单独分发。

打包后不需要把 `talk_data.json` 放在程序同目录。程序会自动在 `%APPDATA%\Talkbox\` 下创建和保存话术数据。

## 说明

拖拽发送依赖目标软件是否支持对应的文字、图片或文件拖放。PDF 的复制和拖拽会传递文件；如果某些聊天窗口不支持拖放，可以尝试复制按钮或双击复制后粘贴。
