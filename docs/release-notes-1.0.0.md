# TalkBOX 1.0.0 发布说明

## 这是什么

TalkBOX 1.0 是把原来的 PySide6 版本完整重写为 **Qt 6 / QML / C++20** 的版本。
功能与交互按原需求（`TalkBOX_PRD_Qt_v1.0.md`）实现，界面按 Windows 11 原生风格重做。

## 主要变化

- **全新的原生外观**：保留 Windows 原生窗口框架（DWM 投影、圆角、缩放边框、Aero 贴边），
  标题栏改由 QML 自绘（应用图标 + 最小化 / 最大化 / 关闭，按钮几何参考 Edge）。
- **分类完全自定义**：不再预置「开场 / 电表 / 报价 / 售后 / 未分类」，分类由你自己创建；
  未分类内容通过虚拟「未分类」筛选查看。
- **卡片点击即复制**：文本复制全文、图片复制位图、PDF 复制文件引用，可直接粘贴到微信等聊天窗口。
- **拖拽发送**：把卡片拖到聊天窗口，文本直接得到正文，图片 / PDF 作为附件。
- **右键 / 「…」菜单**：复制、预览、打开、编辑、重命名、修改分类、在文件夹中显示、删除。
- **备份与恢复**：单个 `.talkboxbackup` 文件（清单 + 数据库快照 + 附件），恢复前校验、
  失败自动回滚，并在替换前自动保留安全副本。
- **纯本地**：不联网、不上传、无遥测，详见 [`PRIVACY.md`](../PRIVACY.md)。

## 安装

| 方式 | 文件 |
|---|---|
| 安装版 | `TalkBOX-1.0.0-setup.exe`（当前用户安装，不需要管理员权限） |
| 免安装 | `TalkBOX-1.0.0-portable.zip`，解压后双击 `TalkBOX.exe` |

- 系统要求：Windows 10 1809+ / Windows 11（x64）。
- 卸载不会删除 `%LOCALAPPDATA%\TalkBOX`（你的话术库），需要彻底清除时手动删除该目录。

## 从旧版升级

旧版（PySide6，0.0.x）使用 JSON 存储，新版使用 SQLite，格式不同，**不能直接覆盖安装**。
旧版仍保留在 `pyside6-legacy` 分支与 0.0.1–0.0.4 的 Release 中。
迁移步骤见 [`migrate-from-legacy.md`](migrate-from-legacy.md)。

## 已知问题

- 从左侧 / 底部拖拽放大窗口时，新露出的边缘可能短暂显示桌面底色，属于 Qt Quick 场景图在
  Windows 上的已知行为（QTBUG-46074 一类），已用整窗不透明底色把影响降到最低。
- 仅提供 x64 构建；32 位与 ARM64 未验证。
