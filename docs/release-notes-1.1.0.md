# TalkBOX 1.1.0 发布说明

## 这是什么

1.1.0 在 1.0.0 的基础上，把「拖拽发送」补成真正的一步到位：拖进聊天窗口松手后，
TalkBOX 可以自动替你按一次 Enter，把消息直接发出去。

## 新增：拖拽后自动发送

提供两种方式，互不冲突：

1. **左键拖拽 + 开关**（默认关闭）
   打开 `设置 → 拖拽发送 → 左键拖拽后自动发送` 后，左键把卡片拖到聊天窗口并松手，
   就会自动按 Enter 发送；开关关闭时，左键拖拽仍然只是把内容放进聊天窗口，不会发送。
2. **中键拖拽**（无需开关）
   按住鼠标中键（滚轮按下）拖拽卡片，松手后自动发送。适合临时发一条、不想改设置的场景。

安全边界：

- 只有聊天窗口**接收**了这次拖拽才会按 Enter；拖回 TalkBOX、拖到空白处、按 `Esc` 取消都不会发送。
- 拖到桌面 / 任务栏 / 资源管理器窗口时不会按 Enter，避免误打开或重命名文件。
- 发送前会确认目标窗口真的在前台；高 DPI 多屏下也能正确定位松手位置。

## 其他改进

- 拖拽提示会跟着变：开启自动发送或使用中键拖拽时显示「松开即可发送」。
- 设置弹窗在窄面板（默认 420 宽）下宽度自适应，不再被裁掉。
- 日志新增自动发送结果事件（只记「是否按下」，不记录内容），`PRIVACY.md` 同步说明。

## 安装

| 方式 | 文件 |
|---|---|
| 安装版 | `TalkBOX-1.1.0-setup.exe`（当前用户安装，不需要管理员权限） |
| 免安装 | `TalkBOX-portable-1.1.0.zip`，解压后双击 `TalkBOX.exe` |

- 系统要求：Windows 10 1809+ / Windows 11（x64）。
- 卸载不会删除 `%LOCALAPPDATA%\TalkBOX`（你的话术库），需要彻底清除时手动删除该目录。

## 从 1.0.0 升级

直接覆盖安装或解压覆盖即可，数据库结构没有变化，话术、分类、附件与备份都会保留。
设置里的「拖拽发送」开关保存在 `%LOCALAPPDATA%\TalkBOX\ui.ini`，默认关闭。

## 已知问题

- 自动发送通过模拟键盘完成。如果聊天软件以管理员权限运行，Windows 会拦截模拟按键，
  此时消息会留在输入框里，需要手动按 Enter（关掉对方的管理员权限即可恢复自动发送）。
- 从左侧 / 底部拖拽放大窗口时，新露出的边缘可能短暂显示桌面底色，属于 Qt Quick 场景图在
  Windows 上的已知行为，已用整窗不透明底色把影响降到最低。
- 仅提供 x64 构建；32 位与 ARM64 未验证。
