# TalkBOX 1.1.2 发布说明

## 这是什么

1.1.2 集中修复了复制、拖拽和整理话术时的交互问题，让图片和 PDF 在聊天窗口中的传递更稳定。

## 交互调整

- **双击复制**：左键单击话术卡片不执行操作，左键双击后才复制文本、图片或 PDF。
- **编辑保留分类**：编辑文本内容时不再自动改成「未分类」；只有主动选择分类时才会修改分类。
- **右键拖动排序**：按住右键拖动话术卡片即可调整顺序，经过其他卡片时会自动腾出位置。

## 图片和文件传递

- 图片复制改为后台处理，避免图片解码和 Windows 剪贴板写入阻塞界面动画。
- 图片拖到聊天窗口时保留原始内容，并延迟清理临时文件，避免聊天软件尚未读取完成就出现空图片。
- 导入的 PDF 和图片发送到微信时保留导入时的文件名，不再显示内部英文或 UUID 文件名。

## 安装

| 方式 | 文件 |
|---|---|
| 安装版 | `TalkBOX-1.1.2-setup.exe`（当前用户安装，不需要管理员权限） |
| 免安装 | `TalkBOX-portable-1.1.2.zip`，解压后双击 `TalkBOX.exe` |

- 系统要求：Windows 10 1809+ / Windows 11（x64）。
- 卸载不会删除 `%LOCALAPPDATA%\\TalkBOX`（你的话术库），需要彻底清除时手动删除该目录。

## 验证

- `tst_system_clipboard.exe` 通过。
- `tst_ui_flows.exe` 通过。
- Release 安装包和便携版均已构建。

## 从 1.1.1 升级

直接覆盖安装或解压覆盖即可，数据库结构没有变化，话术、分类、附件、备份和设置都会保留。
